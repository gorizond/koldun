# Koldun Platform - Reasoning & Iteration Documents

## Обзор
Эта директория содержит документы для итеративной отладки и развития платформы Koldun. Структура организована для поддержки циклических сессий работы над проектом.

## Структура документов

### Основные документы
- **[0_REASONING_TASK.md](0_REASONING_TASK.md)** - Главное ТЗ для итеративной работы
- **[1_ITERATION_ANALYSIS.md](1_ITERATION_ANALYSIS.md)** - Анализ текущего состояния
- **[SESSION_TEMPLATE.md](SESSION_TEMPLATE.md)** - Шаблон для новых сессий
- **[PARALLEL_ANALYSIS_TEMPLATE.md](PARALLEL_ANALYSIS_TEMPLATE.md)** - Шаблон для параллельного анализа

### Организация итераций
```
docs/reasoning/
├── README.md                           # Этот файл
├── 0_REASONING_TASK.md                 # Постоянное ТЗ
├── 1_ITERATION_ANALYSIS.md             # Базовый анализ
├── SESSION_TEMPLATE.md                 # Шаблон сессии
├── PARALLEL_ANALYSIS_TEMPLATE.md       # Шаблон параллельного анализа
└── iterations/                         # Результаты итераций
    ├── 2025-10-31_14-30_session_1.md
    ├── 2025-11-01_09-00_session_1.md
    ├── 2025-11-01_15-45_session_2.md
    └── ...
```

## Workflow итеративной работы

### 1. Начало новой сессии
```bash
# Копировать шаблон с автоматической подстановкой даты и времени
cp SESSION_TEMPLATE.md iterations/$(date +%Y-%m-%d_%H-%M)_session_N.md

# Или с полной автоматизацией имени
SESSION_NUM=1  # или следующий номер
cp SESSION_TEMPLATE.md iterations/$(date +%Y-%m-%d_%H-%M)_session_${SESSION_NUM}.md

# Начать работу с документом
$EDITOR iterations/$(date +%Y-%m-%d_%H-%M)_session_${SESSION_NUM}.md
```

## Ключевые принципы

### Цикличность
- Каждая сессия строится на результатах предыдущей
- Незавершённые задачи переносятся автоматически
- Прогресс отслеживается через метрики

### Документирование
- Все изменения документируются в сессии
- Проблемы и решения фиксируются для будущего
- Создаётся база знаний о проекте

### Автоматизация
- Использование параллельных задач где возможно
- Минимизация контекста через агрегацию
- Промежуточные результаты в временных файлах
