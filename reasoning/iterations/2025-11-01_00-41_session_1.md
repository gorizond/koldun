## Обнаруженные проблемы

### ⚠️ Предупреждение 1: Несоответствие Session.spec.scaling.activeRequests

**Расположение**: Session CRD vs SessionScalingSpec

**Проблема**:
- CRD определяет поле `spec.scaling.activeRequests` (int32)
- Go структура `SessionScalingSpec` в types.go НЕ содержит это поле

**Потенциальное влияние**: Среднее
- Если поле используется в CRD, оно будет проигнорировано контроллером
- Данные могут быть потеряны при обновлении ресурса

**Рекомендация**:
```go
type SessionScalingSpec struct {
    MinDllamas           int32 `json:"minDllamas,omitempty"`
    MaxDllamas           int32 `json:"maxDllamas,omitempty"`
    ScaleUpBacklog       int32 `json:"scaleUpBacklog,omitempty"`
    ScaleDownIdleSeconds int32 `json:"scaleDownIdleSeconds,omitempty"`
    DesiredDllamas       int32 `json:"desiredDllamas,omitempty"`
    // TODO: Добавить поле activeRequests или удалить из CRD
    // ActiveRequests       int32 `json:"activeRequests,omitempty"`
}
```

### ⚠️ Предупреждение 2: Отсутствие RootMemorySpec в IngressBackendSpec DeepCopy

**Расположение**: pkg/apis/koldun.gorizond.io/v1/types.go:1314

**Проблема**:
Метод `IngressBackendSpec.DeepCopy()` не копирует поле `RootMemory`

**Текущий код**:
```go
func (in *IngressBackendSpec) DeepCopy() *IngressBackendSpec {
    // ...
    in.Resources.DeepCopyInto(&out.Resources)
    return out
    // RootMemory НЕ копируется!
}
```

**Рекомендация**:
```go
func (in *IngressBackendSpec) DeepCopy() *IngressBackendSpec {
    // ... existing code ...
    in.Resources.DeepCopyInto(&out.Resources)
    if in.RootMemory != nil {
        memCopy := *in.RootMemory.DeepCopy()
        out.RootMemory = &memCopy
    }
    return out
}
```

### ⚠️ Предупреждение 3: Отсутствие DeepCopy для IngressRootMemorySpec

**Расположение**: pkg/apis/koldun.gorizond.io/v1/types.go

**Проблема**:
Структура `IngressRootMemorySpec` не имеет метода DeepCopy()

**Рекомендация**:
```go
func (in *IngressRootMemorySpec) DeepCopy() *IngressRootMemorySpec {
    if in == nil {
        return nil
    }
    out := new(IngressRootMemorySpec)
    *out = *in
    if in.OverheadMaxRatio != nil {
        value := *in.OverheadMaxRatio
        out.OverheadMaxRatio = &value
    }
    return out
}
```

- Worker (через Dllama)

**Dllama** отслеживает:
- Model (используется для развёртывания)
- Root (координатор)
- Worker (рабочие процессы)
- Ingress (может ссылаться на Dllama)

**Model** отслеживает:
- Job (download, conversion, sizing)

**Root** отслеживает:
- Service
- StatefulSet
- Worker (управляемые root)
- Dllama (владелец root)
- Model (используемая модель)

**Worker** отслеживает:
- StatefulSet
- Service
- Dllama (владелец worker)
- Model (используемая модель)

**Ingress** отслеживает:
- Deployment (backend)
- Service (backend service)
