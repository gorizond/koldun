## Выявленная проблема

Из отчёта аудита (сессия 1) была выявлена проблема **высокого приоритета**:

### Проблема 1: Отсутствие DeepCopy для IngressRootMemorySpec

**Файл**: `pkg/apis/koldun.gorizond.io/v1/types.go:1167`

**Описание**: Структура `IngressRootMemorySpec` не имела метода `DeepCopy()`, хотя содержит указатель на `float64`.

**Структура**:
```go
type IngressRootMemorySpec struct {
    OverheadMaxRatio *float64 `json:"overheadMaxRatio,omitempty"`
}
```

**Потенциальные последствия**:
- Некорректное копирование при клонировании ресурсов Ingress
- Возможные race conditions при изменении shared pointer
- Нарушение инвариантов Kubernetes API machinery

### Проблема 2: IngressBackendSpec.DeepCopy() не копирует RootMemory

**Файл**: `pkg/apis/koldun.gorizond.io/v1/types.go:1268-1292`

**Описание**: Метод `IngressBackendSpec.DeepCopy()` корректно копировал все поля, кроме `RootMemory`.

**Исходный код**:
```go
func (in *IngressBackendSpec) DeepCopy() *IngressBackendSpec {
    // ... копирование других полей ...
    in.Resources.DeepCopyInto(&out.Resources)
    return out  // RootMemory не копируется!
}
```

**Потенциальные последствия**:
- При копировании Ingress ресурса поле RootMemory указывало бы на тот же объект
- Изменение в одной копии влияло бы на другую
- Нарушение семантики DeepCopy

// DeepCopy for IngressRootMemorySpec.
func (in *IngressRootMemorySpec) DeepCopy() *IngressRootMemorySpec {
