## Исправленные проблемы

### 1. Несоответствие структур API
- Model.Spec изменен с Family/Registry на SourceURL/LocalPath
- Token не имеет поля Name
- Использование v1.SchemeGroupVersion вместо v1.GroupVersion

### 2. Проблемы с конвертацией
- runtime.DefaultUnstructuredConverter.ToUnstructured возвращает map, а не принимает указатель
- Правильная обработка unstructured.Unstructured.Object

## Проблемы и блокеры

### 1. Таймауты при запуске тестов
- Некоторые тесты могут требовать больше времени
- Возможно, нужна оптимизация fake клиентов

### 2. Сложность тестирования async кода
- Server.Run() требует контекста и горутин
- Необходимы более сложные моки для полного покрытия

### 3. Зависимости между пакетами
- Многие функции требуют полной инициализации
- Необходимы интеграционные тесты
