### 2. Debug #1: Namespace Issue ✅

**Failure Analysis** (commit b8655ed):
```
pod default/minio-mc terminated (Error)
exit code 1
```

**Root Cause**: minio-mc pod running in `default` namespace, trying to connect to `koldun-minio.koldun:9000`

**Fix Applied** (commit c2b07f7):
```yaml
# Before
kubectl run minio-mc --rm -i --restart=Never --image=minio/mc -- \
  sh -c "mc alias set ... http://koldun-minio.koldun:9000 ..."

# After
kubectl run minio-mc -n koldun --rm -i --restart=Never --image=minio/mc -- \
  sh -c "mc alias set ... http://koldun-minio:9000 ..."
```

**Changes**:
- Added `-n koldun` to kubectl run command
- Simplified MinIO URL (same namespace = short name)

**Result**: Pushed and tested → **STILL FAILED**

### 3. Debug #2: Shell Wrapper Issue ✅

**Failure Analysis** (commit c2b07f7):
```
mc: <ERROR> `sh` is not a recognized command. Get help using `--help` flag.

Did you mean one of these?
        `share`
```

**Root Cause**: `minio/mc` image is a **CLI tool, not a shell environment**
- The image has no shell (`sh`, `/bin/sh`, `bash`)
- Commands must be called directly: `mc <command>` not `sh -c "mc <command>"`

**Fix Applied** (commit 5f9348a):
```yaml
# Before (commit c2b07f7)
kubectl run minio-mc -n koldun --rm -i --restart=Never --image=minio/mc -- \
  sh -c "
    mc alias set myminio http://koldun-minio:9000 minioadmin minioadmin &&
    mc mb myminio/koldun-models || true
  "

# After (commit 5f9348a)
kubectl run minio-mc -n koldun --rm -i --restart=Never --image=minio/mc -- \
  mb --ignore-existing http://minioadmin:minioadmin@koldun-minio:9000/koldun-models || true
```

**Key Changes**:
1. Removed shell wrapper entirely (`sh -c`)
2. Call `mc mb` directly as pod command
3. Use inline credentials syntax: `http://user:pass@host:port/bucket`
4. Add `--ignore-existing` flag (equivalent to `|| true`)
5. Single command (no need for alias + mb sequence)

**Result**: Pushed and tested → **STILL FAILED** 😞
