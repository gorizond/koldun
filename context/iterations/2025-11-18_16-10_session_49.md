```markdown
### E2E Test Success Criteria

✅ **All criteria must pass**:
1. Model CR reaches Ready status
2. Ingress CR creates backend pod
3. Backend responds to `/v1/models` with model list
4. POST `/v1/chat/completions` creates conversation in NATS KV
5. Operator automatically creates Session/Dllama/Root/Worker CRs (within 10 seconds)
6. Kubernetes creates pods: 1 dispatcher + 1 root + 3 workers (within 20 seconds)
7. Dispatcher assigns work to workers via NATS
8. LLM worker processes inference request
9. Response is returned to client (2-5 minutes for CPU inference)
10. Resources are cleaned up after TTL expiration
```

### 2. Created Automated E2E Test Script ✅

**File**: `hack/test-e2e.sh` (12.8KB, executable)

**Features**:
- ✅ **Automated E2E workflow** - complete testing from start to finish
- ✅ **Prerequisite checks** - kubectl, curl, namespace validation
- ✅ **Resource validation** - Model, Ingress, Backend readiness
- ✅ **Port forwarding** - automatic setup/cleanup
- ✅ **API testing** - `/v1/models` and `/v1/chat/completions` endpoints
- ✅ **Resource monitoring** - Session, Dllama, Root, Worker CRs
- ✅ **Pod verification** - dispatcher, root, workers creation
- ✅ **Topology validation** - 1 root + N workers
- ✅ **Skip inference mode** - fast testing without waiting for CPU inference
- ✅ **Cleanup** - automatic resource cleanup on exit
- ✅ **Debug output** - colored logs, detailed error messages

**Configuration Options**:
```bash
NAMESPACE=koldun              # Target namespace
MODEL_NAME=qwen3-0.6b        # Model to test
INGRESS_NAME=qwen3-ingress   # Ingress to test
BACKEND_PORT=8082            # Port forward port
TIMEOUT=300                  # Resource creation timeout (5 min)
INFERENCE_TIMEOUT=600        # Inference timeout (10 min)
SKIP_INFERENCE=true          # Skip slow CPU inference
CLEANUP=true                 # Cleanup resources after test
```

**Usage**:
```bash
# Quick test (skip inference)
./hack/test-e2e.sh

# Full test with inference (slow!)
SKIP_INFERENCE=false ./hack/test-e2e.sh

# Custom configuration
NAMESPACE=test MODEL_NAME=tinyllama ./hack/test-e2e.sh
```

### 3. Created E2E CI Workflow ✅

**File**: `.github/workflows/e2e-test.yaml`

**Workflow Configuration**:
- **Trigger**: Push to any branch (code/chart changes), PRs to main, manual dispatch
- **Timeout**: 15 minutes
- **Environment**: k3d cluster (v1.28.5-k3s1)
- **Components**: NATS with JetStream, MinIO (minimal setup)
- **Test Mode**: Resource creation only (SKIP_INFERENCE=true by default)

**Steps**:
1. ✅ Build operator image (`koldun:test`)
2. ✅ Create k3d cluster (`koldun-e2e`)
3. ✅ Install NATS Helm chart with JetStream
4. ✅ Deploy MinIO (minimal setup, memory storage)
5. ✅ Create test model bucket
6. ✅ Install Koldun operator with test image
7. ✅ Create test Model CR (no actual download)
8. ✅ Create test Ingress CR (minimal configuration)
9. ✅ Run E2E test script (`hack/test-e2e.sh`)
10. ✅ Collect debug info on failure
11. ✅ Cleanup k3d cluster

**Why Skip Inference in CI**:
- CPU inference takes 2-5 minutes per request
- Too slow for CI pipeline (would need 10-15 minute timeout)
- Resource creation validation is sufficient
- Full inference tested manually/locally

**Manual Trigger Options**:
```yaml
workflow_dispatch:
  inputs:
    skip_inference:
      description: "Skip CPU inference test (faster)"
      type: boolean
      default: true
```
